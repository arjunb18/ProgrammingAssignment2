How the estimate works

A language model writes one token (about ¾ of a word) at a time, and each token requires reading every active weight from memory once. Generation speed is therefore close to memory bandwidth ÷ model size. The check finds your memory size and bandwidth, adds room for the context cache and runtime, and compares that with each model's 4-bit download.

Model list current as of 29 September 2026. Speeds are estimates for a single user with a ~4,000-token context; real results vary with drivers, settings and other running apps.
